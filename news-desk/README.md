# News Desk

**Its job:** create our own content and onboard creators.

**What it produces:** text, images and video.

## What lives here

- **Content formats:** what each kind of our own content looks like, for the launch categories (PLAN.md step 1.3).
- **Our own content:** the tools that prepare it and load it into the shared content store. Images and video files go into the content store's storage, not into this repository.
- **Creators:** the list of creators to invite, and how they are onboarded through creator accounts in the app (steps 1.3 and 4.4).

## Rules

- What passes to Product is defined by the hand-over agreement (step 0.7). No content is written before it is agreed.
- Projects never copy code between each other; this shared repository is the only route.
- Frameworks and dependencies aren't chosen yet.
